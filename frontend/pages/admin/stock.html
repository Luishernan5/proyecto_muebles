Ajuste rápido de stock

Para reponer con el catálogo y carrito de abasto, abre Zona administración — Abasto. La tienda pública es solo para clientes. Aquí puedes sumar o restar por ID (positivo = entrada, negativo = salida). El inventario no puede quedar negativo ni superar el tope del servidor (STOCK_CEILING_PER_PRODUCT).
